# 极光影院主题

整站默认启用极光深色主题，顶栏太阳 / 月亮按钮可切换原有浅色主题。登录页和注册页也提供切换入口。偏好保存在当前浏览器的 `vistamirror.ui.theme`，刷新和跨标签页同步；不写入服务器配置。

## 实现

- `runtime/aurora.css`：统一深海蓝底色、蓝紫主操作、青色状态、卡片、表单、表格、菜单、弹窗和日志配色；包含各业务页旧硬编码颜色的兼容规则。
- `runtime/aurora.js`：在页面绘制前读取主题偏好，处理切换和跨标签页同步；存储不可用时仍可切换当前页面。
- `runtime/assets/theme/aurora-cinema.png`：生成的影院星空背景，用于仪表盘欢迎区域和登录页兜底。
- `runtime/index.html`、`runtime/register.html`：最后加载主题样式，并提供带无障碍名称的主题按钮。

覆盖仪表盘、内容排行、质量盘点、缺集管理、播放历史、MoviePilot、115、STRM、影巢、Docker、用户、客户端、通知、媒体库、网络服务、AI、任务、封面工坊及其公共弹窗。现有 DOM ID、业务请求和保存流程保留，封面绘制内容与海报选择逻辑不变。

内容面板使用实色，只有顶栏使用透明模糊；弹窗统一单层遮罩。支持 `prefers-reduced-motion`。320px 顶栏将文字品牌缩为图标，避免新增主题按钮导致换行。
