# VistaMirror 界面视觉规范

## 共用样式入口

- `runtime/ui-tokens.css`：字体、字号、尺寸、圆角、间距变量。由基础、Docker、仪表盘、登录、注册样式导入，独立页面也能使用。
- `runtime/ui-system.css`：主应用共用组件规范，位于各模块样式之后加载。保留业务布局；集中管理标题、输入控件、常规按钮、卡片、表格及弹层。
- 页面已有字号声明已迁移到共用变量，避免旧的 12.5、13.5、14.5 等字号继续独立变化。

## 字体与尺寸

| 用途 | 规范 |
| --- | --- |
| 正文和表单控件 | 14px，系统无衬线字体 |
| 辅助说明和状态标签 | 12px |
| 分区标题 | 16px，字重 600 |
| 弹层标题 | 20px，字重 600 |
| 页面标题 | 桌面 24px，手机 22px |
| 主要统计数字 | 28px，等宽数字 |
| 控件高度 | 桌面 38px，手机主要操作 44px |
| 圆角 | 控件 10px，卡片 16px，弹层 20px |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32px |
| 页面左右边距 | 桌面 24px，手机 12px |

日志与代码保持等宽字体。搜索和状态标签可使用胶囊样式，开关、单选框、图标按钮保持其专用结构。日志虚拟列表保留原行高。封面生成参数及图像中的文字字号不属于管理界面字号，不改动。

## 布局

页面优先使用公共 topbar 显示一次标题及说明。仪表盘欢迎区和 Docker 工具栏保留专用结构，但共享标题尺度。媒体配置、115、STRM 和影巢的重复页头已收敛；状态与操作保留。

封面工坊按实际可用宽度分配三栏，窄桌面使用两栏，手机纵向显示。宽表格可在自己的滚动容器中横向滚动，不能扩大整个页面。

## 新增界面

使用变量和现有组件类，不再新增近似字号。常规表单优先使用 `field`、`settings-card`、`primary-btn`、`ghost-btn`。特殊布局规则归属对应模块，共用尺寸规则归属 `ui-system.css`。历史 `!important` 覆盖由共用组件规则集中处理，不为每个新页面再增加一套皮肤。

## 2026-09-16 网络与服务

TMDB 海报兜底、网络代理迁入“网络与服务”卡片入口，以独立弹窗编辑和保存。TMDB 使用 `/api/tmdb/config`，只更新现有存储中的 TMDB 字段；代理沿用 `/api/network/config`。不迁移或清空已保存数据。媒体服务器保存不再依赖代理读取成功。弹窗支持未保存关闭确认、失败保留草稿、环境变量只读及过期测试结果丢弃。卡片隐藏 Token 和代理凭据。

验证：3 项 TMDB 保存接口测试、5 项媒体保存测试通过；模拟接口验证两项独立保存、关闭恢复、只读、延迟测试响应、失败草稿及 320px 弹窗。未部署，未对真实服务执行配置写入。
