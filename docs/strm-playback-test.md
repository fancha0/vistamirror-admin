# STRM 客户端直链修复与试播

2026-09-19：从网页版下载接口切换到加密的客户端下载接口，修复已观察到的“文件大小超出限制，请使用115电脑端下载”解析错误。协议依赖固定为 p115cipher 0.0.5.1，兼容现有 Python 3.11 镜像；必须重新构建镜像。

## 开发版更新

在 Mac 项目目录执行：

```sh
cd /Users/sy/my-todo
./scripts/deploy_fnos_dev.sh
```

此脚本同步当前工作区源码并重建开发版（默认 18091 / 18099），保留远端 data-dev；因此也会包含当前工作区已完成的 UI 改动。脚本需要能够登录飞牛 SSH。

## 试播

1. 刷新开发版管理页面，打开 STRM 直连。
2. 输出目录使用容器路径，默认挂载下填 `/测试/strm115`；播放地址填 `http://192.168.5.9:18099`。
3. 如配置无变更，无需重新生成现有签名 STRM。
4. 点击“刷新视频列表”，选择影片，再点击“测试播放链路”。
5. 测试绕过直链缓存，用客户端接口解析，并最多读取 1024 字节；结果显示耗时和是否返回有效 Range 响应。
6. 测试成功后在 Emby 实际起播、拖动进度。服务器读取成功不等于任意客户端/外网环境均可播放。

新增“签名链接 + 文件名”格式：文件名作为编码后的 name 参数追加，不改变已有签名校验。开启后需保存并同步才会更新 STRM 文本。已有文件采用智能更新：相同内容跳过，变化则更新。

缓存按账号、pick_code、播放器 User-Agent 隔离。诊断链接仍是签名地址，不在页面暴露 Cookie 或最终 CDN 地址。Cookie 失效、账号下载权限和网路问题会作为测试失败反馈。

## 短播放地址与原始文件名

选择“短地址 + 原始文件名（推荐）”，生成的文本为：

```text
http://192.168.5.9:18099/d/s_<稳定短标识>.mkv?/%E5%BD%B1%E7%89%87%E5%90%8D.mkv
```

文件名进行 URL 编码，避免中文、空格、`&`、`#` 等影响播放；播放器如何展示编码取决于客户端。短标识由服务端密钥和文件 ID 生成，包含 144 位认证信息，不是裸文件 ID 或 pick_code；持有完整地址即可播放。服务重启后地址不变，轮换签名密钥会使旧地址失效。旧版 `exp=0&sig=...` 地址继续可用。

已有文件迁移：

1. 部署新版，选择短地址格式，点击“保存配置”。
2. 点击“更新已生成 STRM”。此操作读取现有索引，只改当前输出目录中的已有 STRM，不扫描 115、不下载影片、不删除文件，也不重置同步断点。缺失文件会跳过，目录外路径和符号链接会拒绝更新。
3. 核对更新、无变化、缺失及失败数量，再点击“提交 Emby 刷库”。
4. 如果 Emby 仍显示旧地址，刷新对应影片的媒体信息，并检查实际 `.strm` 文件内容是否已变更。无需删除影片或重新入库。

旧配置保留原来的链接格式，不会因升级静默重写文件；全新配置默认使用短地址格式。播放链路测试也会返回当前格式的地址。旧版签名链接两种格式仍可选，保存后再次更新即可切回。

## STRM 日志终端（2026-09-21）

打开“运行日志”后每 2 秒轮询最新记录，按时间从旧到新排列。可选择 100 / 500 / 1000 条、搜索关键词、筛选 INFO / WARN / ERROR、暂停、自动跟随、放大、复制或下载当前筛选结果。搜索和导出只覆盖当前载入窗口，不代表全部历史。上滚会关闭自动跟随；关闭弹窗、页面进入后台或登录失效后停止更新。

同步会记录目录扫描、视频生成、内容未变跳过、非视频跳过、文件错误；更新现有 STRM 会记录缺失和失败原因；播放解析会记录缓存命中和耗时。每次任务最多输出 500 条普通文件明细，超过后提示限额并继续记录目录进度、错误和结果汇总。旧记录不会补造历史过程。文件部分失败与整轮失败分别展示。

日志接口仅向已登录管理员开放，从日志文件尾部最多读取 4 MiB；认证信息和播放地址中的敏感部分进行脱敏。日志界面更新与内容筛选使用本地模拟接口验证；实际 115 播放仍以部署后的客户端起播为准。
