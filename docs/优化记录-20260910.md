# 2026-09-10 最新改动稳定性优化

范围：在现有未提交的 Docker 管理和仪表盘改动上完善可靠性、数据准确性及刷新行为。未提交 Git、未发布、未操作实际容器，保留既有业务数据及原型文件。

## Docker 管理

- 修复官方镜像标签、显式 Docker Hub 前缀解析；私有仓库和 digest 固定引用显示不支持检测。
- 比较容器实际使用的镜像 ID，而非可能已被重新拉取的标签；兼容多架构 index 和平台 manifest digest。
- 本地或远端 digest 缺失显示未知，不再误报更新或全部最新。
- 更新前拦截 VistaMirror、自动删除、暂停和 Swarm 容器；远程容器继续通过 Compose 更新。
- 更新保留原运行状态和匿名卷，清理网络端点的运行时字段，复用显式 IP 配置；健康检查通过后清理旧容器。
- 停止、重命名、创建、启动及健康检查纳入失败恢复；回滚错误明确显示，清理旧容器失败作为警告保留。
- 对同一容器的活动更新任务去重；服务重启后将无法恢复的历史活动任务标记为中断，保留记录供检查。
- 缓存容器重启策略和 Docker 版本 60 秒，配置修改或重建后失效；镜像检测按主机合并执行并缓存 10 分钟，重建后失效。
- 合并活动列表、卡片和弹窗的状态轮询：执行中每 2 秒、空闲每 5 秒；隐藏页面停止轮询。
- 主机切换时丢弃旧更新检测响应；日志弹窗切换时丢弃旧日志响应；搜索高亮保留原文本转义。

VistaMirror 容器通过宿主机原有 Compose 配置执行拉取和重建。可用 `APP_INFRA_SELF_CONTAINER` 指定自定义容器名或 ID；新版镜像同时带有应用保护标签。

## 仪表盘

- 媒体计数、用户、连接状态、最近入库、媒体库和趋势分开加载；失败显示上一次成功时间，不阻塞其他面板。
- 低频数据按 5 分钟刷新，近期内容与任务按 1 分钟刷新；手动刷新可重新请求各面板。
- 新增只读趋势聚合接口，按时区统计最近 30 天，可在前端切换 7/30 天。
- 每页查询 500 条，仅取必要统计字段；聚合结果缓存 5 分钟。最多 100 页，并在分页间检查 25 秒预算；达到限制或遇到缺失日期明确显示统计未完整。
- 最近入库卡片单独读取最近 100 条，不再随趋势拉取大量海报信息。
- 修正空媒体库展开按钮的隐藏样式和空状态布局。
